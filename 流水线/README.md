# 当前保留的流水线组件

`提取与生成管线/` 保存抽取、绑定、校验、对齐与计分的公共实现，`史料总库.xlsx` 是现有三档史料池建档的数据源。安装依赖见 `提取与生成管线/requirements.txt`；模型调用凭据从 `DEEPSEEK_API_KEY` 环境变量读取。

核心文件：`_论证树一次性抽取.py`、`source_binding.py`、`校验.py`、`_整树LLM对齐.py`、`频次聚合.py`、`measurement.py`。它们是已有组件，**不代表当前论文方案已经通过端到端复现**。`measurement.py` 的计分口径须与 `文档/当前版本与待办.md` 所列待决事项核对后才能用于正式结果。

旧 `实验.py`、`批量实验.py` 和相关测试依赖旧目录布局，已移入顶层 `归档/`。A03/A04 的旧编排、旧提示词和旧说明也在同一归档目录中，仅供追溯，不应直接运行以生成当前 CCI/ECI。
