# 脚本索引

## 日常主流程

统一命令见 `python 实验.py --help`。下表按操作顺序排列。

| 阶段 | 文件 | 输入 → 输出 |
|---|---|---|
| 手工材料/段落 | `脚本/手工整理.py` | 人工 CSV → 史料池或原文_clean.json |
| 导入已有 | `脚本/导入已有.py` | 已有论文目录 → 实验数据中的基准与 run |
| 史料分档 | `脚本/派生SML史料池.py` | source_pool.json → S/M/L 池 |
| 生成 | `脚本/Q条件生成.py`、`脚本/A条件生成.py` | 史料池与任务 → 生成论文；API |
| 抽取 | `脚本/_论证树一次性抽取.py` | 已整理段落 → run_论证树.json；API |
| 绑定 | `脚本/source_binding.py` | 树 → 绑定修复及首次备份 |
| 校验 | `脚本/校验.py` | 树 → 结构错误列表/退出码 |
| 对齐 | `脚本/_整树LLM对齐.py` | 参考树与模型树 → 对齐轮次、输入锁、汇总；API |
| 聚合 | `脚本/频次聚合.py` | 已完成对齐 → 频次聚合.json |
| 编排 | `批量实验.py` | 已准备的基准和模型 run → 各阶段产物与批量 CSV |

## 公共模块

| 文件 | 职责 |
|---|---|
| `脚本/公共库.py` | 论文读取、段落骨架和树节点工具 |
| `脚本/管线公共.py` | 配置、JSON 原子写入、输入指纹与树文件查找 |
| `脚本/measurement.py` | ACI/SCI 与频次投票计算；不是命令入口 |
| `脚本/提示词模板.py` | Q/A 共用生成约束 |

## 迁移与兼容

主流程脚本路径保持原样。辅助脚本的旧路径已迁移，旧命令请按 `整理备份/迁移清单.json` 替换。整理前代码保存在同目录 ZIP 中。

## 当前口径注意

`measurement.py` 当前会将某父节点下唯一直属 C 从命题指标分母中排除；结构边仍按自身定义计算。本次整理保留这一已有实现，并以专项测试记录。该规则是否符合研究定义需要单独的方法学判断，不能由目录整理代替。
