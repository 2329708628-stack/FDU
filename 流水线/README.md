# 宋史史料库论证重建实验流水线

用 LLM 基于史料池生成宋代史论文，再把论文论证树与**人类学者论文**的论证树做盲态对齐，
量化「模型在多大程度上复现了人类的论证结构与史料使用」。

- **当前口径**：V2.0，指标为 CCI / ECI
- **最近修订**：2026-10-25（人类基线 10 篇全量重做 + 指标术语订正 + 结果表数值回算）
- **包内完整链路**：A03、A04（各 30 run 齐全）

> 本 README 是入口文档。复现步骤与结构说明见 [`交接说明.md`](交接说明.md)，
> 逐阶段操作见 [`.trae/skills/songshi-experiment-pipeline/references/执行手册.md`](.trae/skills/songshi-experiment-pipeline/references/执行手册.md)。

---

## 先看这三条（不知道会全链路出错，且不报错）

1. **每个正文自然段 = 恰好 1 个 C 节点**，不跳过、不合并、不跨段。
   人工 CSV 分段曾把 27–60 个自然段合并成 6–33 个处理块，直接压低节点数，
   让「人类树大小」失去跨实验可比性，并制造出假的「反转放大效应」。
2. **报告写 CCI / ECI，JSON 里叫 `ACI` / `SCI`**。算法没改名，只是术语换了。
3. **ECI 不在 `overall` 里**：CCI 取 `main.overall.ACI`，ECI 取 `main.SCI`。
   写 `main.overall.SCI` 会 KeyError。

## 快速上手

```bash
# 0）环境与密钥（密钥用环境变量，不要写进文件）
pip install -r 提取与生成管线/requirements.txt
export DEEPSEEK_API_KEY="自己的密钥"

# 1）校验三档池（--check 只校验不写盘）
python3 .trae/skills/songshi-experiment-pipeline/scripts/建档三档.py --id A03 --check

# 2）生成 30 篇模型论文
python3 A03_实验记录/生成A03.py

# 3）全链路：装配 → 统一名册 → 批量 → A7 合并 → 汇总 → 报告
python3 A03_实验记录/装配A03.py
python3 A03_实验记录/统一名册A03.py
python3 A03_实验记录/批量A03.py
python3 A03_实验记录/A7合并A03.py
python3 A03_实验记录/汇总A03.py
python3 A03_实验记录/build_report_A03.py
```

所有脚本根路径都是 `Path(__file__).resolve().parent.parent`，**无硬编码绝对路径**。

**交付前必做**：`提取与生成管线/deepseek_env.sh` 内嵌了一份真实 API 密钥，对外发送前清空。

## 核心概念

### 实验设计

**2 条件 × 3 档 × 5 轮 = 30 篇模型论文**

| 维度 | 取值 |
|---|---|
| 条件 | **Q** 中性提问 / **A** 给定观点 |
| 档位 | **S** 引用片段 / **M** 200 字上下文 / **L** 400 字上下文 |
| 轮次 | R1–R5 |

三档是**同一批引文、只扩展上下文长度**，三档条数与引文集合完全相同。

### 论证树（三层）

| 层 | 含义 | 来源 |
|---|---|---|
| **A** | 全文唯一结论 | 代码推导（取自结语段） |
| **B** | 章节节点 | 由标题机械推导 |
| **C** | 段落主张 | 每个正文自然段 1 个 |
| **M** | 史料 | 名册，编号取自史料总库 |

旧版本是四层（含 B 小节、C 子命题），现统一为三层。

### 指标

| 指标 | 定义 | 分母 |
|---|---|---|
| **CCI** 观点收敛度 | 被模型覆盖的人类命题数 / 人类命题总数 | B + C − 合并节点（**含**无史料 C） |
| **ECI** 证据结构收敛度 | 模型保留的人类结构边数 / 结构边总数 | 结构边（无史料 C 不产边，自动退出） |

- 每篇做 **10 轮盲态整树对齐**，主口径 `k≥6`，稳健口径 `k≥4`。
- 正式定义在 [`脚本&数据/分析结果/A01_实验记录/计分定义.md`](../分析结果/A01_实验记录/计分定义.md)（v2.0）。
- 旧名 ACI（软 F1）/ SCI（轮间软 Jaccard）**已作废**，勿再引用。

---

## 三条硬约束

1. **不改模型论文**。只允许做引用标记规范化（空格变体），不得改文字内容。
2. **共享名册必须覆盖人类树全部引用**，且 `A1.sources` 强制等于完整名册（`exact_shared_roster`）。
3. **A-7 是后处理**，不重跑对齐，只重算票；报告须同时给原始与 A-7 两套数。

统一口径（`提取与生成管线/实验设置.json`）：`rounds=10`、`main_k=6`、`robust_k=4`、
`cross_level=true`、`exclude_A=true`、`source_id_policy=exact_shared_roster`。
**任何实验都不得改动这些值。**

## 常见坑（前五个）

| # | 症状 | 原因 / 修法 |
|---|---|---|
| 1 | 引用标记匹配失败 | 有空格变体，见 `references/坑位表.md` 第 1 条 |
| 2 | 人类树 C 节点数异常地小 | 分段被合并了，回到「每自然段 1 个 C」重洗 |
| 3 | `main.overall.SCI` KeyError | ECI 在 `main.SCI`，不在 `overall` 里 |
| 4 | 报告里 S/M/L 有差异但无规律 | 三档本就无单调效应，差异多为噪声，勿当结论 |
| 5 | 报告静默丢实验 | 用 `sed 's/A10/B01/g'` 建实验导致，改用 `新增实验.py` 脚手架 |
