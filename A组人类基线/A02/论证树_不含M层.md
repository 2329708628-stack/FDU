- 论文：南宋富民闭粜现象及政府应对策略

A1〔结语〕南宋富民闭粜源于官方财政困境、依赖富民、政策失当及富民自保，其破坏性后果促使政府以市场调控和劝谕应对，体现荒政利益取舍与稳定难题。
├─ B1〔一 南宋富民闭粜的原因〕南宋富民闭粜是官方财政困境、依赖富民、吝啬赏格与科配失当，及富民惜售待价、防备官府共同作用的结果。
│  ├─ C1.1（P3）劝分政策本以富民乐从为理想，但南宋实际执行中富民闭粜成为突出现象，其成因各不相同。
│  ├─ C1.2（P4）南宋官方赈灾过度依赖富民捐输，常平义仓不足，劝分负担过重，导致富民不愿出米。
│  ├─ C1.3（P5）南宋荒政中劝分所获米粮远多于官拨常平义仓，已成为救济的主要来源。
│  ├─ C1.4（P6）劝分由补充性举措转变为主要救济手段，与南宋军费和地方财政紧张导致常平义仓被挪用密切相关。
│  ├─ C1.5（P7）南宋政府吝惜推赏，纳粟奖励待遇降低，使富户得不到实际利益并丧失对官方的信任。
│  ├─ C1.7（P9）此段为南宋时期关于劝分奖励诏令的引述性过渡。
│  ├─ C1.9（P11）南宋劝分奖励的出粜下限和上限均有提升，奖励要求更严、等级划分更明确，相关褒奖制度也更完善具体。
│  ├─ C1.10（P12）推恩下限提高使偏远富户难以获赏，朝廷推恩不实、吝惜官爵，削弱了对富户的出粟激励。
│  ├─ C1.11（P13）地方政府按户等一例科配，富户等第与实存余粮不符，导致无粮可粜，政策粗放并加重民户负担。
│  ├─ C1.12（P14）富民或出于吝啬和待价获利心态，或因担心劝分变为常年课纳及对官府不信任，而选择闭粜存粮。
│  └─ C1.13（P15）南宋富民闭粜现象普遍，是官方依赖劝分、吝赏科配与富民惜售、待价及防备常年征敛共同作用的结果。
├─ B2〔二 南宋富民闭粜的影响及政府应对策略〕富民闭粜会危及饥民生计、诱发乡村贫民危机和盗乱，政府一面以市场调控开源，一面在地方严罚与中央劝谕之间形成应对分歧。
│  ├─ C2.1（P17）富民闭粜使赈灾粮不足、饥民无以为生，并可能迫使贫民啸聚为盗。
│  ├─ C2.2（P18）官方赈济存在城乡差异且多止于城郭，乡村贫民更依赖富户，故富民闭粜对其生计影响更大。
│  ├─ C2.3（P19）在官赈难及乡村的情况下，劝分是乡村灾民获得救济的重要途径，富户闭粜会使乡村贫民陷入危机。
│  ├─ C2.4（P20）贫民因闭粜抢夺粮食会干扰救济秩序，激化社会矛盾，成为社会不安定隐患。
│  ├─ C2.5（P21）政府从开源角度积极运用市场调控，以免税、高价吸引商贾运粮和增加官方平价粮源来平抑粮价。
│  ├─ C2.6（P22）针对富民闭粜，地方政府主张从重严罚，中央则强调爱民、不得骚扰，以劝谕使富户自愿出粜，二者态度不一致。
│  ├─ C2.7（P23）地方官员多主张以从重严罚处置闭粜富民，以强硬手段维护劝分秩序和官方救济主动权。
│  ├─ C2.8（P24）地方官员认同严惩闭粜富民和作乱贫民，并借权宜处置维持救济秩序，确保官方掌握救济主动权。
│  ├─ C2.9（P25）中央朝廷主张劝谕富民自愿出粜，严禁官吏骚扰富户，并对骚扰行为予以处罚。
│  ├─ C2.10（P26）官方态度强调为政以爱民为本，主张官员以爱民之心劝谕富民出粟，而非专恃科敛技巧。
│  └─ C2.11（P27）官方对富民闭粜态度存在争论和反复，其实质是劝分政策设计与执行之间的矛盾，即殷勤劝谕与强制责罚的取舍。
├─ C3.1（P29）南宋富民闭粜之所以突出，既体现富民阶层成长，又源于财政窘境与救灾责任向富户转移，导致闭粜频发。
└─ C3.2（P30）富民闭粜破坏社会秩序，官方应对有市场调控与劝谕处罚分歧，反映荒政制度设计中利益取舍与稳定难题。
