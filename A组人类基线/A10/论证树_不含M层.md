A1〔四 结论〕月桩钱本质上是中央与路级机构之间的军费调度，县至州、州军至屯驻大军为实体发送环节，州司之间仅为形式性发送。
├─ B1〔一 州级及州以下的月桩钱〕月桩钱实体存在于州县之间，县以下仅有窠名，县级措置后送州储存。
│  ├─ C1.1（P3）县级措置的各类杂税属于月桩钱窠名，表明月桩钱实体已存在于州县之间。
│  ├─ C1.2（P4）月桩钱在县级行政区有定额征收并由县承担，其窠名虽有州级财政来源，却日益减损而难以足额。
│  └─ C1.3（P5）月桩钱依中央定额经州军、县自上而下征调，县以下仅有窠名，其实体存在于州县之间。
├─ B2〔二 州军、诸司和大军军前之间的月桩钱〕州军与监司均与屯驻大军军前之间存在月桩钱往来，州军为实体发送主力，监司仅在有余力时发送。
│  ├─ B2.1〔（一）州军和屯驻大军军前之间〕州军按监司指令将月桩钱实体发往屯驻大军军前，是月桩钱筹集的主要部分。
│  │  ├─ C2.1.1（P8）上供、经制、系省等月桩钱窠名多形成于州军财政，但中央规定的窠名来源日渐减损。
│  │  └─ C2.1.2（P9）州军奉监司命令将月桩钱实体发往屯驻大军军前，是月桩钱筹集的主要部分。
│  └─ B2.2〔（二）监司到屯驻大军军前〕监司在有余力时以宽剩钱等经费供应屯驻大军月桩钱，但这种发送并非普遍强制义务。
│     ├─ C2.2.1（P11）监司可将宽剩钱桩管申报以拨充月桩，但并非所有监司都有余财或供应大军月桩的强制义务。
│     ├─ C2.2.3（P13）除州军外，转运司、提刑司等监司也有责任以移用钱等经费支持屯驻大军月桩钱。
│     ├─ C2.2.4（P14）归纳前文：州军与大军军前之间肯定存在月桩钱，监司与大军军前之间虽不普及也有往来。
│     └─ C2.2.5（P15）监司与大军军前之间同属月桩钱存在范围，但其发送不普遍，常通过通判代收代送，仍可视为实体发送。
├─ B3〔三 州司之间的月桩钱〕州军与监司之间不存在月桩钱实体流动，只存在指挥下发、监督归属和形式性发送。
│  ├─ C3.1（P17）监司对月桩钱缺口不负弥补义务而由朝廷应副，此情形到中后期有所改变。
│  ├─ C3.2（P18）州军与监司之间不存在月桩钱实体输送，州军仅按监司指令将钱直接送往屯驻大军军前，转运司无使用权。
│  └─ C3.4（P20）月桩钱无需实体经过监司层面，监司与诸州之间只有指挥下发和名义划拨，故属形式发送。
├─ C4.1（P22）人户到县之间仅存在月桩钱窠名，县到州军之间则属月桩钱成型后的实体发送。
├─ C4.2（P23）州军与监司层级之间不存在实体发送，因州军直接供应屯驻大军，不宜按路分转运。
├─ C4.3（P24）州军与监司之间虽无实体发送，但存在监司指导和形式归属，州级窠名减少强化了对县级以下窠名的搜集。
├─ C4.4（P25）监司奉指挥以宽剩钱等余财供应屯驻大军，但其财多存于州军军资库，因而发送具有形式性。
└─ C4.5（P26）月桩钱根本上是中央与路级机构之间的军费调度，州军只是执行监司转达命令的地方发送单元。
