# A04 生成条件与提示词存档

## 主题
唐宋时期瓷窑官（"官监"）制度与宋代瓷业管理

人类基准论文：《宋代瓷窑官与瓷业管理制度浅析》（A组交付包_20261018/A04/第二轮复现）

## 条件定义（Q/A 两档提示条件 × S/M/L 三档史料池）
- **Q（中性研究问题）**：唐宋时期瓷窑官（"官监"／监窑官）是何时、如何产生的？其在宋代的身份级别、差遣权力、隶属关系与职责事务如何演变？瓷窑官制度与宋代制瓷业的发展之间是什么关系？
- **A（给定核心观点）**：宋代瓷窑官承袭中晚唐五代藩镇旧制而经中央化改造，其身份级别、差遣权力、隶属关系与职责随瓷业发展而演变，既推动制瓷业繁荣，又在南宋晚期制度废弛中阻碍瓷业发展。
- **史料池三档**（同一批引文，仅扩展的上下文长度不同；来源=史料总库.xlsx）：S=核心引文（引用片段）；M=含该引文的 200 汉字原文上下文；L=含该引文的 400 汉字原文上下文（前 200 字即 M 档）。三档引文集合完全相同，共 20 条。

## 完整生成提示词模板（v1.0）

### A. 系统指令（固定，逐字使用）

```
你是一位研究宋史/制度史与陶瓷史的学者。你将收到一份编号史料池和一项写作任务，请仅依据该史料池撰写一篇结构完整的学术论文。

规则：
1. 论证所依据的史料必须来自史料池；凡引述史料，必须在句末以 [A04-Mxx] 格式标注其编号，引文文字须取自史料池所给文本，不得改写。
2. 允许一般性学术背景表述（如研究史、常识性制度说明），但不得引入史料池之外的具体史料引文或数据。
3. 正文需分节论述，使用中文数字节标题；章节结构与展开顺序自行安排，不作规定。
4. 正文规模与一篇规范期刊论文相当（正文不少于3000汉字）。
5. 以一段以"综合史料池"开头的总括段落结束全文，给出你的最终论点。
```

### B. 用户消息（逐轮实例化）

```
写作任务：〔条件文本：Q 或 A，见上文条件定义，逐字使用〕

史料池（共{N}条，编号为条目唯一标识）：

[A04-M2] 出处：…｜引文：…
（逐条列出，格式统一；不呈现核验状态列，避免核验差异影响生成）

请依据以上史料池完成任务。
```

### C. 实例化与记录规则
- 6 条件共用同一模板；Q/A 条件文本来自本文件"条件定义"，逐字使用，不得轮间改写。
- 每轮生成目录：`A04_实验记录/生成轮次/{条件}{档}_R{n}/`，内含 `论文_模型原始输出.md`、`meta.json` 与 `提示词_实例.md`。
- 轮次独立性：各轮之间不共享上下文，不提供任何前轮输出。
- 生成参数：model=deepseek-chat, temperature=0.7, max_tokens=32768，流式输出，finish_reason='stop' 方为合格。
