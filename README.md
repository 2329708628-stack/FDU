# 宋史论文论证重建实验：组内共享包

本目录从 FDUROP 工作区筛选，供少数组员在**私有 GitHub 仓库**查看当前方法、脚本与已审核的 A 组人类基线。整理日期：2026-10-26。

## 从这里读起

1. `文档/实验进展与脚本梳理_20261025.md`：实验设计、脚本位置与尚待完成事项。报告初稿的人工审核状态已由后续报告更新。
2. `文档/引文审核应用报告_20261025.md`：A01–A10 独立引文段的审核及应用结果。
3. `流水线/README.md` 与 `流水线/交接说明.md`：A03/A04 历史流水线的入口和复现说明。它们仍包含旧计分口径及旧待办，不能直接视为最终论文方案。
4. `文档/论文v3.txt`：论文方法方案草稿；与脚本现状的差异见第 1 项。
5. `文档/人类论文编号对应表.txt`：A/B/C 组的论文编号映射。原始论文 PDF 未收入本包。

## 文件范围

- `流水线/提取与生成管线/`：抽取、绑定、对齐、计分等公共脚本。
- `流水线/A03_实验记录/`、`流水线/A04_实验记录/`：历史实验的编排脚本、提示词模板与史料池输入。
- `流水线/史料总库.xlsx`：建档时使用的史料总库。
- `A组人类基线/清洗与审核/`：A 组重洗、校验和人工引文审核脚本与报告。
- `A组人类基线/A01` 至 `A10`：审核后的树、自然段文本与审核记录，属于派生计分基线。

没有收入：API 密钥、本机环境文件、论文 PDF、生成论文全文、A03/A04 旧对齐输出、历史归档与缓存。这个共享包适合阅读和继续开发，**尚不足以离线复算全部历史结果**。如需复算，应补齐经过授权的数据和生成输出，并先统一计分定义。

## 运行环境

安装 `流水线/提取与生成管线/requirements.txt` 中的依赖。需要调用模型时，在自己的机器上设置 `DEEPSEEK_API_KEY` 环境变量；不要把密钥写入仓库。`批量A03.py` 与 `批量A04.py` 的共享副本已改为明确要求环境变量。

本目录只是一份待上传副本；原工作区和其中的历史文件均未改动。提交 GitHub 前检查 `文件清单.json`。
