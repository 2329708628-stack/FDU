## 一、实验目标与预期流程

论文 v3 的目标是比较模型论文与原人类论文在**命题**和**论证关系**上的收敛程度。设计为 30 篇宋史论文，Q（中性问题）/A（给定中心论点）× S/M/L（三档史料上下文）× 两个生成模型 × 每条件 3 次，共计划 1080 篇模型论文。推理档位固定为 medium。完整路径是：论文及脚注清洗 → 固定 M 名册和三档史料池 → 提取人类论证树 → 生成模型论文 → 用同一规则提取模型树 → B/C 命题对齐 → CCI/ECI 与文章层统计。

论文 v3 将 C 定义为段落锚定的论证命题：每个正文段**至多**一个 C；纯引文、原始记录、数字和过渡段可以没有 C。CCI 是人类 B/C 命题被模型覆盖的比例，模型侧精确率另报。ECI 比较 B/C 之间的直接父子边及 B/C→M 边。A 和固定研究问题 Q 不进入计分分母。论文写明人类论文完整抽取两次，以及每对树 10 轮对齐、6 票为主阈值、4 票为稳健阈值。

这些是**拟采用的论文方案**；现存脚本和历史试验有不同口径，不能直接视为该方案已执行。

## 四、当前口径冲突和具体问题

1. **默认规则已明确，论文表述待同步。**用户当前决定默认每个正文自然段一个 C；仅对单独成段的引文人工审核，确认其是否应独立计分或并入所支持的主张。2026-10-25 自然段基线与此默认规则相符；论文 v3 仍写“每段至多一个 C，纯材料段可跳过”，正式方法部分需要按最终规则修改。
2. **`--drop-quote-only` 不是人工归并。**该开关删除 C；它不记录引文段归向，不把该段 M 明确转给其所支持的主张。直接启用会改变证据边，且无法解释为何归到某个节点。
3. **计分说明互相矛盾。**`分析结果/A01_实验记录/计分定义.md` 将 ECI 描述为论点→史料边；论文 v3 与包内 `measurement.py` 均把直接 B/C 父子边也计入。交付包 README 又称“无史料 C 不产边”，但代码仍为其计算父子边。正式重算前应固定一种定义，并同步代码、论文和说明。
4. **“独子合并”只是计数启发式。**`measurement.py` 从 CCI 的 B/C 计数中扣除父节点下唯一的 C，却仍在 ECI 中保留该 C 的边；“只有一个直属 C”也不能单独证明两者语义相同。需人工验证或改成明确的论证单元映射。
5. **生成与对齐版本不同。**A03/A04 包内为六条件×五轮的历史试验；论文 v3 是两生成模型×三轮。人类新树用 `DeepSeek-V4-Pro-0813`，旧模型树记录为 `deepseek-chat`，这是既有的抽取模型差异，需在比较时说明或单独评估；本次只调整人类论文整段引文的清洗规则，**不能因此推定模型论文必须全部重抽**。只有模型侧同样出现待审核的独立引文段，或其输入/提取规则发生实质变化时，才针对受影响的树考虑重抽。
6. **文档数字需统一。**交付包 README 写旧 CCI 分母 148→378，而重洗报告表格给出的合计是 154→378；应以逐篇树和同一版计分程序重新生成汇总，不再手抄总数。
7. **交付环境仍待整理。**交付包 README 指出 `deepseek_env.sh` 内含密钥；具体文章的批量脚本也会读取它。对外发送前应移除该凭据，并用环境变量运行。此报告未读取或复制密钥内容。

## 五、建议的下一阶段：审核独立引文段，再重算受影响结果

**第一步：只列出单独成段的引文。**保留“每自然段一个 C”的默认结果，从人类树中筛出 `quote_only` 标记及人工发现的漏标独立引文段。审核表按 P 编号记录：`文章ID、P编号、是否独立成段的引文、是否含独立主张、保留或归并、归属目标C、该段原M、审核后M归属、理由、审核人/状态`。普通短段及无史料段不因长度或无 M 自动进入归并。

**第二步：只修订受影响的树与边。**原文、自然段基线和已完成的常规 M 绑定不动；另存审核后的计分树。对确认为附属引文的 C，记录其去向，并将该段已有的 M 关联到确认的目标 C；重新计算受影响 B 的 M 并集。不能确认归属的保留为待定，不自动绑前段。模型论文先筛查是否存在同类例外；若不存在，沿用现有清洗和抽树产物。

**第三步：冻结计分定义。**主指标若沿用论文 v3，CCI 保持人类侧覆盖率；模型侧精确率和 Jaccard 可作补充，不能把“匹配数/模型总数”改名为原 CCI。ECI 明确报告证据边、父子边及合并值的分子分母。确定一对多配对和人工归并后的边去重规则。

**第四步：重算受影响的比较。**选择一份权威 `measurement.py` 并指定审核后人类树版本。若人工操作改变了参与匹配的 C 节点或文本，原有配对需重新检查/对齐；若只改变 M 归属且节点不变，可固定原配对重算 ECI。旧 A03/A04 结果仍只作历史对照。模型树是否重抽由模型侧实际异常决定，不作为这次修订的默认步骤；论文 v3 的正式生成规模、模型与轮数另在试验台账核对。
