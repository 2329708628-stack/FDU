## 四、对下游结论的三条影响

### 1. CCI / ECI 全部作废，重做后数值将系统性下降

`CCI = 被模型覆盖的人类命题数 / 人类命题总数`。分母从 154 → 378（2.45 倍），
分子（30 篇模型树，C 均值 23.4）不变。粗估 A01 的 CCI 会从 0.28–0.44 降到 0.15 上下。
这是真实值，不是退化 —— 也反证了「每个正文自然段 1 个 C」必须是硬规格。

### 2. 「反转放大效应」的效应量被旧数据夸大，须重新估计

基线表原结论：人类树越小，Q−A 反转越大（A05 32 节点反转 −0.046，A10 12 节点反转 −0.219）。

按自然段重做并统一 CCI 分母口径后：

| | A05 | A10 | A05 / A10 |
|---|---|---|---|
| 旧（处理段） | 32 | 7 | **4.57 倍** |
| 新（自然段，同口径） | 36 | 24 | **1.50 倍** |

旧数据里 A05 的树看起来是 A10 的 4.57 倍，统一粒度后实际只有 1.50 倍 ——
**旧差距中约 67% 是分段粒度造成的假象**（A05 压缩比 1.2×，A10 压缩比 2.1×）。

结论：
- **方向可能仍成立**（新数据下 A10 树仍较小，反转仍较大），不应轻率推翻；
- **但效应量被夸大约 3 倍**，旧的 −0.046 / −0.219 这组对比数值不能直接引用，
  须用新 CCI 在统一粒度下重新估计；
- 该效应此前被当作已验证规律，而其证据链建立在跨篇不可比的节点数之上。

> 本报告前一版曾称「A05 与 A10 计分节点相等（17 vs 17）因而该效应不成立」，
> 那是基于错误口径（`B + C − 无史料 C`）得出的结论，已作废。

### 3. 计分分母口径（已澄清）

「21 式口径」= `B + C − 合并节点`，其中「合并」指父节点只有一个直属 C 时，
该 C 与父表达同一命题，故并入父计数、不单独进分母。

**该口径不扣无史料 C**，这点必须讲清楚：
旧 A01 有 7 个无史料 C（C1.1、C1.1.2、C1.3.2、C2.1、C3.1、C3.2.1、C4.1），
它们在旧报告里全部保留在分母内（若扣除则分母为 23 而非 21）。
理由成立：无史料 C 也是命题，CCI 衡量的是命题覆盖，与该命题有没有史料无关。

**本报告先前使用的 `B + C − 无史料 C` 是错误口径**，已从 251 更正为 378。

三个口径在新数据下的实际差异：

| 口径 | 公式 | A01 | 10 篇合计 |
|---|---|---|---|
| **采用** | `B + C − 合并` | 58 | **378** |
| 全不扣 | `B + C` | 61 | 387 |
| 错口径（勿用） | `B + C − 无史料 C` | 37 | 251 |

合并扣减在新数据下几乎失效：旧 A01 单篇就能扣掉 9 个合并节点，
新 A01 只扣 3 个。原因是旧树为四层（A→B 节→B 小节→C→C 子），
父候选有 13 个（A1 + 12 个 B）摊薄 18 个 C，独子自然多；
新树为三层（A→B→C），父只剩 12 个 B 承载 49 个 C（均值 4 个/B），独子仅剩 3 个。

**CCI 与 ECI 分母本就不同，无需额外扣减：**

- CCI 分母 = `B + C − 合并`（含无史料 C，共 378）
- ECI 分母 = 人类基准结构边总数，无史料 C **不产生边，自然不在分母内**，
  所以 136 个无史料 C 会自行退出 ECI，不必人为剔除。

## 五、已知偏差与待办

1. **模型树抽取模型不同（最重要）**：30 篇模型树由 `deepseek-chat` 抽取，
   本次人类树用 `DeepSeek-V4-Pro-0813`。跨树对齐前需按同一模型重抽模型树，
   否则抽取模型差异会成为混淆变量。
2. **A05 的 M 名册使用率偏低**：对齐总库后为 32/49（65%），仍有 17 条从未被
   正文圈号引用。属上游名册遗留问题，非本次重洗引入
   （对齐前为 36/72 = 50%，其中 23 条是总库外条目，见第七节）。
3. **无史料 C 共 136 个（占 328 个 C 的 41%）**：A04 20/35、A05 20/32、A06 14/26。
   它们照常计入 CCI 分母，但**不产生任何结构边，会使 ECI 分母天然小于 CCI 分母**，
   这是 ECI 数值系统性低于 CCI 的直接原因之一，属真实分布，非缺陷。
4. **空页码孤儿 M**：A03 7 条、A09 6 条、A02 5 条未被任何段落引用，见各篇 `重洗报告_<篇>.md`。
5. **A04 结语段为人工回补**：full.md 原文无独立结语标题，按旧人工标注的
   P25（384 字）回定位到自然段 P42(207)+P43(177)，已写入 `结论段_覆盖.json`。
6. **B 层跨篇不可直接相加**：各篇章节层级深度不同（A01 含二级小节，A02 无），
   B 数量差异是论文结构差异，非管线错误；汇总时需按篇分别处理。

## 六、树层级从四层改为三层的连带影响

旧 A01 树为四层（A→B 节→B 小节→C→C 子命题），本次统一为三层（A→B→C）。
这除了让各篇可比之外，还有一个副作用：**合并扣减规则几乎失效**（见第四节 3）。
若沿用旧四层结构，新 A01 段落切细后会产生大量独子 C，
分母会被合并规则吃掉一大块；三层结构下 49 个 C 均匀挂在 12 个 B 下，此问题自然消失。

## 七、M 名册对齐到史料总库（后处理）

### 缘起

`原文_clean.json` 的 `materials` 来自论文脚注提取 + LLM 判定，
条数与总库「汇总统计」的「史料条数」列一致（A01 64、A05 72…），
但**多于总库「史料库」工作表的实际收录数**（A01 53、A05 49…）。

差额 57 条是建库时**「找不到对应条目」而主动删除**的，总库才是权威名单。

### 为什么必须删

三档史料池（S/M/L）由总库生成，**模型侧只能看到总库收录的史料**。
人类树若保留总库外的 M，这些 `C→M` 边模型永远无法复现，
会系统性压低 ECI，等于给模型造了一批注定拿不到分的边。

### 执行方式与影响

`python 重洗_A组/align_roster_to_lib.py --apply`（原文件自动备份为 `.bak_名册对齐`）。
只做「删条目 + 同步 sources」的确定性后处理，**不重跑 LLM**：
C 的 claim 由段落文本决定，与 M 名册无关，重抽也不会改变 claim。

### 对齐后的连带效应

- **CCI 分母不变（378）**：删 M 不改变 C 节点数，且无史料 C 照进分母。
- **ECI 分母下降**：57 条来源被移除，对应的结构边随之消失，ECI 分母变小。
