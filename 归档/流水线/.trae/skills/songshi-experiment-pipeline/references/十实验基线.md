## 一、主题与 CCI 分母

CCI 分母 = `B + C − 合并节点`（合并 = 父节点只有一个直属 C 时该 C 并入父计数）。
**不扣无史料 C** —— 无史料 C 也是命题，CCI 衡量命题覆盖。
旧值 = 旧处理段粒度实测；新值 = 自然段级重做后实测。

## 三、两条旧规律的重估

### 1. 同构假说 —— ⚠ 待重验

**A 条件与人类论文 B 层结构的同构程度，决定 Q−A 差距的大小。**

- 正向证据：A05（A 反超 0.046）、A10（A 反超 0.219）、A09（几乎持平 0.013）
- 反向证据：A07（差 0.415，A 崩坏）、A08（差 0.225）
- 崩坏计数：A07 有 5/15 个 A 条件 run 的 CCI(n=6) < 0.15；A08 有 5/15 < 0.30；
  A09 只有 1/15 < 0.30；A10 为零。

B 层由章节标题机械推导，**本次重做后 B 层数量完全未变**（10 篇合计 59 → 59），
故该假说的自变量本身是稳定的，结论方向可能保留，但效应量需用新 CCI 重算。

### 2. 反转放大效应 —— ⚠ 效应量被夸大约 3 倍，须重新估计

> 原表述：「人类树越小，同构假说的效应越强」（A05 32 节点反转 −0.046，A10 12 节点反转 −0.219），
> 机制解释为粒度稀释。

**同口径重算**（CCI 分母 = B + C − 合并）：

| | A05 | A10 | A05 / A10 |
|---|---|---|---|
| 旧（处理段） | 32 | 7 | **4.57 倍** |
| 新（自然段） | 36 | 24 | **1.50 倍** |

旧数据里 A05 的树看起来是 A10 的 4.57 倍，统一粒度后实际只有 1.50 倍，
**旧差距中约 67% 是分段粒度造成的假象**。

结论：**方向可能仍成立**（新数据下 A10 树仍较小、反转仍较大），不应推翻；
但旧的 −0.046 / −0.219 对比数值不能直接引用，须用新 CCI 重新估计效应量。

## 五、报告横向对比表的写法

`NODES` 字典键必须是**全部已完成实验 + 新实验**，值为该实验人类树的计分节点数
（A+B+C 中排除零 sources 的节点）。
两处 `for p in [...]` 列表与 `NODES` 键集合保持一致。每加一个实验都重跑一次并核对行数。

**自 2026-10-25 起，`NODES` 应取自新基线树**：
`归档/数据集/数据清洗后论文/<篇>/03_实验输出/Q_A_实验/A_human_自然段基线/run_论证树.json`

计算口径（可直接复用 `脚本&数据/重洗_A组/verify_baseline.py` 的实现）：

```
CCI 分母 = total_B_nodes + total_C_nodes − 合并节点数
合并节点数 = 父节点只有一个直属 C 的 C 节点数（父 = C_level 各节点的 parent）
```

⚠ **不要扣无史料 C**。无史料 C 计入 CCI 分母（它们是命题）；
它们不产生结构边，会自动退出 ECI 分母，无需人为剔除。
误用 `B + C − C_nodes_without_sources` 会得到 251（正确值 378）。
