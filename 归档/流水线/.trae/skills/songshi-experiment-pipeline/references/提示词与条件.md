# 提示词与条件文本

## 系统指令（逐字使用，只改实验编号）

```
你是一位研究宋史/财政史的学者。你将收到一份编号史料池和一项写作任务，请仅依据该史料池撰写一篇结构完整的学术论文。

规则：
1. 论证所依据的史料必须来自史料池；凡引述史料，必须在句末以 [<ID>-Mxx] 格式标注其编号，不得改写引文文字。
2. 允许一般性学术背景表述（如研究史、常识性制度说明），但不得引入史料池之外的具体史料引文或数据。
3. 正文需分节论述，使用中文数字节标题；章节结构与展开顺序自行安排，不作规定。
4. 正文规模与一篇规范期刊论文相当（正文不少于3000汉字）。
5. 以一段以"综合史料池"开头的总括段落结束全文，给出你的最终论点。
```

规则 3 是实验设计的核心：**不给结构**，模型自己组织章节，这样 CCI 才有区分度。
规则 5 的"综合史料池"段落是装配脚本用来定位结尾的锚点，不能删。

## 用户消息模板

```
写作任务：{条件文本}

史料池（共{N}条，编号为条目唯一标识）：
[<ID>-M1] 出处：…｜引文：…
[<ID>-M2] 出处：…｜引文：…
（逐条列出，格式统一；不呈现核验状态列，避免核验差异影响生成）

请依据以上史料池完成任务。
```

三档 S/M/L 是**同一批引文、不同上下文长度**：三档引文集合完全相同，只有"给模型看的上下文"
长度不同——S=引用片段本身，M=含该引文的 200 汉字原文上下文，L=含该引文的 400 汉字原文上下文
（前 200 字即 M 档）。数据源统一为工作区根 `史料总库.xlsx` 工作表「史料库」的
`引用片段` / `史料原文_200字` / `史料原文_400字` 三列。因此提示词里的"共{N}条"三档相同，可硬编码。

入池质量门：`引用片段` 在 `史料原文_200字` 中的字符覆盖率 ≥ 0.7 才入池，否则该条剔除并记入
`档位说明_<ID>.json` 的 `dropped_no_context` / `dropped_low_coverage`。这保证 M/L 确实是
"含同一引文的更长上下文"，而不是换了一批史料。

| 档 | 内容 | A03 字数 | A04 字数 |
|---|---|---|---|
| S | 引用片段 | 1288 | 621 |
| M | 史料原文_200字 | 8999 | 4000 |
| L | 史料原文_400字 | 17997 | 7994 |

生成脚本必须按 run 名的第二个字母取档（QS/AS→S、QM/AM→M、QL/AL→L），
不能像 A04–A10 那样固定读 `pool_text_S.txt`——那会让档位轴彻底失效（见坑位表第 12 条）。

## Q 条件文本（中性研究问题）

写成一句或两句**开放问句**，指向人类论文的核心问题，但不给答案、不给结构。

已用实例：

| 实验 | Q 条件 |
|---|---|
| A09 | 北宋对西夏的食盐运销管控是如何展开的？盐钞在这一过程中扮演了怎样的角色？ |
| A10 | 南宋月桩钱的发送在不同行政层级之间呈现怎样的形态？它是如何在县级、州军级、监司级与大军军前之间运作的？ |

写 Q 的要领：问"如何展开/呈现怎样的形态/存在怎样的关系"，不要问"是不是/是否导致"。

## A 条件文本（给定核心观点）

取人类论文摘要的**浓缩论点**，一句话讲清因果链或层级形态，不带章节结构。

已用实例：

| 实验 | A 条件 |
|---|---|
| A09 | 北宋以解盐运销为核心的对夏经济制裁贯穿宋夏博弈始终，盐钞由国防补给工具逐步异化为敛财与争利手段，最终导致陕西路金融体系崩溃 |
| A10 | 月桩钱在地方行政层级间的存在形态不同——人户至县仅为窠名阶段，县至州军为实体发送，州军至监司为形式发送，监司至大军军前则视余财而定，根本上月桩钱存在于中央与路级之间 |

A 条件文本的**结构同构度**是决定 CCI 的核心变量（见 `十实验基线.md`）：
A 文本的组织方式与人类论文 B 层越同构，A 条件 CCI 越接近甚至超过 Q 条件。
所以 A 文本不要刻意压平，也不要在写实验记录时"美化"，原样使用人类论文的论点压缩版。

## 生成参数

| 项 | 值 |
|---|---|
| model | `deepseek-chat` |
| temperature | 0.7 |
| max_tokens | 32768 |
| stream | true |
| 轮间隔 | 4 秒 |
