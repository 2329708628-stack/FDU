# CCI / ECI 计分定义（v2.0）

本实验采用覆盖型收敛指标，以人类论文论证树为基准。旧版 ACI（软 F1）与 SCI（轮间软 Jaccard）不再作为正式报告口径。

## 1. CCI：Claim Convergence Index（观点收敛度）

衡量模型复现人类基准命题的程度：

`CCI = 被模型覆盖的人类基准命题数 / 人类基准命题总数`

- 统计 B、C 层命题，A 层仅作参照。
- 某父节点仅有一个直属 C 时，按既定规则与父节点合并计数，避免同一命题重复进入分母。
- 同时报告 B 层、C 层和总体 CCI。
- 模型侧精确率另作辅助指标，不并入 CCI。

## 2. ECI：Evidence Convergence Index（证据结构收敛度）

衡量模型保留人类基准“论点—史料”结构关系的程度：

`ECI = 模型保留的人类基准结构边数 / 人类基准结构边总数`

- 结构边指论点节点到史料节点的有向关系。
- 节点先经语义对齐映射到统一类别，再比较结构边。
- 全池绑定等污染节点按既定规则剔除，不进入分母。

## 3. 频次投票

每篇模型论文进行 10 轮盲态整树对齐：

- 主结果：匹配频次 `k >= 6/10`。
- 稳健结果：匹配频次 `k >= 4/10`。
- QL_R3 的排布异常按单独复核记录处理，并同时保留原始值。

CCI 回答“观点是否复现”，ECI 回答“观点与史料的连接关系是否复现”。轮间稳定性应另行报告，不再使用 ECI 表示。
