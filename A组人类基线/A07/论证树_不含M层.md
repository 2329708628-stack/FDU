- 论文：非常之费：宋代财政体系中的救荒经费\*

A1〔余论〕宋代救荒经费虽多元，但救荒与用兵同属非常之费且相互借支侵夺；用兵之费侵夺救荒经费更为普遍，是评估救灾水平不可忽视的财政因素。
├─ B1〔一 三司（户部）财政的救荒〕三司（户部）财政主要通过允许地方截拨上供米间接支持救荒，但受上供制度严格管控，并非救荒经费的主要来源。
│  ├─ C1.1（P3）三司（户部）作为最高理财机构直接支拨钱物救荒并不常见，其对救荒的支持主要体现在允许地方截拨上供米。
│  ├─ C1.2（P4）上供物资中的谷类属于三司（户部）财政，截留上供米救荒的记载实际上体现了三司（户部）财政对救荒经费的支持。
│  ├─ C1.3（P5）灾荒后户部检放灾伤并宽减上供额度，既缓解转运使筹集税粮压力，也为截留上供提供了可能。
│  ├─ C1.4（P6）灾荒后宽减转运使上供额与截拨上供米几乎同时进行，二者并行可缓解灾伤。
│  ├─ C1.5（P7）宋代截拨上供米救荒的记载频繁，主要用于赈粜、赈济，也用于以工代赈。
│  ├─ C1.6（P8）截拨的上供米出粜后一般须归还转运使或候丰熟补还，有时则由内藏帑钱补足灾年岁计。
│  └─ C1.7（P9）朝廷虽允许灾荒时截拨上供，但管控严格，户部常不愿减放，故三司（户部）上供米并非救荒经费的主要来源。
├─ B2〔二 内藏财政的救荒〕内藏财政由皇帝直接掌控，以赐借三司代充上供和充常平籴本等方式支持救荒，并渐成国家应急储备。
│  ├─ C2.1（P11）内藏库由皇帝直接掌控，属中央财政体系的一部分，主要用于水旱兵革等非常之费，而非仅供皇室消费的私财。
│  ├─ C2.2（P12）内藏库救荒支出可观且使用灵活，主要通过赐借三司以代充上供和充常平仓籴本两种方式支持救荒。
│  ├─ C2.3（P13）灾荒年份内藏库直接支拨钱物给三司以代充上供，缓解三司财政压力，构成对救荒的变相支援。
│  ├─ C2.5（P15）内藏库对三司的支援由名义上的借贷逐渐变为事实上的赐予，内藏库实际成为国家的应急储备库。
│  ├─ C2.6（P16）两宋君主还经常直接出内藏库财物作为救荒资金，以下列举内藏财政参与救荒的实例。
│  ├─ C2.8（P18）内藏库多以财物充常平仓籴本，但因实物多且无转输机构，救荒财物常付户部或转运司变卖、统筹支拨。
│  ├─ C2.9（P19）奉宸库等内库所储珍宝虽偶用于救荒，但实物变现困难且有损国威，故并不常见。
│  ├─ C2.10（P20）宋代君主以内藏库赈灾使天子私财逐渐演变为国家应急储备库，内藏财政支出职能淡化则会削弱其财政后备地位。
│  └─ C2.11（P21）君主以内藏私财参与救荒与宋代“召和气”的祖宗之法相关，被视为反思自身并感召和气、缓解灾伤之举。
├─ B3〔三 朝廷财政的救荒〕朝廷财赋在北宋救荒中仅为补充，南宋因常平义仓衰落而管理严格、数额充足的封桩财赋救荒作用增强。
│  ├─ C3.1（P23）王安石变法后宰相掌握新法财赋，元丰改制后户部财权分化为左曹常赋与右曹朝廷财赋两个系统。
│  ├─ C3.2（P24）北宋后期至南宋，朝廷财赋数额巨大，储存于京师库藏和地方封桩，其数量甚至超过户部与内藏财赋。
│  ├─ C3.3（P25）朝廷财赋不承担国家经常之费，主要用于军需、赈济灾伤等非常之用，救荒是其常见用途之一。
│  ├─ C3.4（P26）北宋朝廷封桩米仅是常平、义仓救荒的补充；南宋常平、义仓衰落后，封桩财赋在救荒中的作用逐渐增强。
│  ├─ C3.7（P29）京师朝廷封桩财赋多支降会子间接救荒，地方封桩财赋多支给钱谷直接救荒，但均须奉朝廷旨意方可支用。
│  └─ C3.9（P31）宋代朝廷对封桩财物管理严格，借支程序复杂且多要拨还；南宋频繁以封桩钱米救荒，主因常平义仓不足而封桩充足。
├─ B4〔四 地方财政的救荒〕州县仓作为地方财政储存之所，设置普遍并承担赈贷等救荒职能，但支用须报朝廷，私发缺乏制度保障。
│  ├─ C4.1（P33）宋代地方财政源于州县留州财赋，都仓、省仓是地方财赋的主要储存之所。
│  ├─ C4.2（P34）州县仓设置普遍，对灾荒救济具有更强应急性；北宋中期以前赈贷多出省仓。
│  ├─ C4.5（P37）州县仓在北宋救荒中多承担赈贷等职能；南宋因归属混乱救荒减少，但仍发挥一定救济作用。
│  └─ C4.6（P38）州县仓救荒虽作用不小，但支用须申报朝廷，私发官廪缺乏制度保障且受阻碍，影响其救荒作用进一步发挥。
├─ C5.1（P40）军粮仓与备荒仓相互依存、通融，根本原因在于饥馑与兵革同属非常之费，导致救荒与用兵经费相互借支侵夺。
├─ C5.2（P41）常平仓储转化为军粮有制度规定，灾年常因军粮乏绝被挪借，影响其赈济功能，此做法直到南宋才有所限制。
├─ C5.3（P42）常平仓钱谷常被直接拨充军费或兑籴军粮，官方籴本向军储倾斜，使备荒功能受到削弱。
├─ C5.4（P43）许多原本用于救荒的物资被划拨为军粮，地方州郡不经朝廷下诏便将救荒物资充作军粮的做法也普遍存在。
└─ C5.5（P44）宋代军费开支在财政中占比极高，用兵之费对救荒经费的侵夺更为普遍，是评估宋代救灾水平时不可忽视的财政因素。
