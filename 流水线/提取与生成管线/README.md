# 史学论证重建实验 · V2.0

日常运行从 **实验.py** 开始；完整操作见 [使用说明](使用说明.md)，全部脚本见 [脚本索引](脚本索引.md)。

```text
实验.py                 主流程统一命令入口
批量实验.py             按 run 编排抽取、绑定、校验、对齐、聚合
实验设置.json           当前测量口径和投票轮数
测试.py                 离线回归测试
脚本/                   正式流程实现与公共模块
工具/
  01_数据准备/          全库清洗、脚注判定、上下文定位与补全
  02_核验导出/          人类基准核验、语义抽检、全库导出
  03_维护验证/          重复抽取验证、全库重跑
  04_历史审查/          固定预实验样本的专项检查
实验数据/               单篇实验输入和输出
整理备份/               整理前代码备份与路径迁移清单
```

## 快速开始

在本目录打开终端（Python 3.10+）：

```powershell
python 实验.py --help
python 实验.py 测试 -v
python 实验.py --preview 批量 --paper A05
```

`--preview` 只显示将要执行的命令，不运行步骤。所有相对路径以本目录为准。
模型调用使用 `DEEPSEEK_API_KEY`；依赖见 `requirements.txt`。

## 正式流程

材料整理 → S/M/L 分档 → Q/A 生成 → 段落与引用整理 → 抽取 → 绑定与校验 → 人工审阅 → 对齐 → 聚合。

已有树可以从绑定与校验开始。人类参考树须先准备、校验并审阅；批量入口只处理模型 run。

```powershell
python 实验.py 分档 实验数据/P01
python 实验.py 生成Q 实验数据/P01 1 "中性研究问题" S
python 实验.py 生成A 实验数据/P01 1 S "给定核心观点"
# 完成段落/引用整理后：
python 实验.py 批量 --paper P01 --runs Q_run_1_S,A_run_1_S
```

每个步骤的输入格式、人工审阅点、续跑规则见 [使用说明](使用说明.md)。
`工具/` 是按需使用的辅助流程，不要求全部依次运行。

## 数据位置

- `实验数据/<论文>/`：本包运行的实验数据；主流程默认使用这里。
- `../数据集/数据清洗后论文/`：全库整理的人类论文与基准；不少辅助工具使用这里。
- 二者不是同一个目录。用 `实验.py 导入` 将准备好的基准/run 复制到实验目录，具体名称见使用说明。
- V1.0 保留为历史版本；不要将旧口径产物当作本版聚合结果。
