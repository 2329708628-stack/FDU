│  ├─ C1.5（P7）宋廷采纳以断绝对夏食盐贸易来加重其财政压力的建议，严禁民间私市，改以解盐补给边民。
│  ├─ C1.6（P8）宋廷以禁青白盐困夏的策略实施后，沿边市场转向内地解盐，制裁初见成效。
│  ├─ C1.7（P9）党项未因盐禁屈服，反以军事骚扰迫使宋廷开放盐禁；经济攻略仍是对夏战略重心。
│  ├─ C1.8（P10）主持者因私议刺杀失败而重启盐禁，却引发内地骚动并遭贬官。
│  ├─ C1.9（P11）宋廷继续禁止青白盐并通解盐，以削弱党项，并未因和谈而放弃禁令。
│  ├─ C1.10（P12）官盐难敌质优价廉的青白盐，宋廷降价仍未能占领市场；禁盐事倍功半，反而刺激私贩。
│  └─ C1.11（P13）朝臣从财政角度质疑禁青白盐政策，认为官方调控难绝流通，盐法目的逐渐转向回笼收入。
├─ B2〔二 北宋中期钞法改革阶段〕北宋中期，宋廷将解盐融入入中与盐钞体制以筹军费，钞盐法创立后经官控扩张，由国防补给转向政府敛财。
│  ├─ C2.1（P15）西夏新主嗣位后推行扩张称帝，宋廷被迫加强西北边防以应对侵地野心。
│  ├─ C2.2（P16）西夏称帝后，宋廷立即禁绝互市并废榷场，但西夏拒绝赏赐显示反宋决心。
│  ├─ C2.3（P17）宋廷重启入中制度以筹军需，其性质由战时补给转为常规保障，并以茶引作为报偿。
│  ├─ C2.4（P18）入中虚估使官方损利加剧，诱发茶法混乱和军粮筹集危机，改革迫在眉睫。
│  ├─ C2.5（P19）宋廷允许以解盐支付入中报偿，将解盐引入军需金融体系，促进流通并减少官方亏损。
│  ├─ C2.6（P20）针对虚估而推行的盐钞法以实钱入中、改造盐钞和限价，降低军需补给损失。
│  ├─ C2.7（P21）军事失败后宋夏议和，长期经济制裁促成缓和，但财政重心倾斜与赋税激增加重负担。
